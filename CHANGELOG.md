## [0.1.0] - 2026-09-16

### Added

- Offline-first Thai PDF/image extraction with digital-text and Tesseract paths.
- Thai normalization, Buddhist Era dates, official-letter schema, confidence, and provenance.
- Python API, CLI, FastAPI sync/async jobs, SQLite retention, Redis/arq worker, and OpenAI-compatible provider.
- Ionic Angular web demo, TypeScript SDK, Docker Compose, OpenAPI snapshot, migration, CI, tests, and contributor documentation.
- SVG and PNG brand assets for Thai Document Intelligence.
