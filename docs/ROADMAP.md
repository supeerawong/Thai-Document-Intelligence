# Roadmap

- **v0.1 — Official Letter MVP:** PDF/image loading, digital text and Tesseract OCR, normalization, dates/numbers, provenance, CLI, sync/async API, Ionic UI, Docker, and synthetic tests.
- **v0.2 — OCR Quality:** PaddleOCR, preprocessing, quality benchmark, mixed-page improvements, and manual correction UI.
- **v0.3 — Agent Ready:** MCP server, published TypeScript SDK, completion webhooks, and richer OpenAI-compatible/Ollama configuration.
- **v0.4 — More Documents:** orders, announcements, minutes, invoices, and custom versioned schemas.
- **v0.5 — Production Storage:** PostgreSQL, S3-compatible artifacts, resumable jobs, metrics, and backup/restore guidance.
- **v0.7 — Extensibility:** stable provider interfaces, community schema registry, and evaluation CLI.
- **v1.0 — Stable:** stable Python/API/schema contracts, migrations, security review, reproducible benchmark, and upgrade guide.

RAG/chat, workflow builders, multi-user/RBAC, hosted SaaS, and native mobile packaging are outside the v1.0 scope.
